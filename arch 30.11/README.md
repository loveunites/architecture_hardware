# Суть работы
В рамках работы были изучены принципы аппаратной виртуализации и архитектура систем ввода-вывода. Выполнена проверка поддержки виртуализации на личном компьютере, разобраны ключевые термины. Проведен анализ выбора архитектуры гипервизоров, расчет переподписки ресурсов и сравнение виртуальных машин с контейнерами. Также изучены виды интерфейсов, топологии соединений и методы расчета пропускной способности шин.
